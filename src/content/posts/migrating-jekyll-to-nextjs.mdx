Migrating a well-established Jekyll site to Next.js is a high-stakes operation. One wrong move and you could lose years of SEO equity. Here's how I approached a recent migration that maintained 100% of the client's organic traffic.

## The Challenge

The client had a Jekyll blog with:
- 200+ posts with established rankings
- Custom URL structures
- Hundreds of backlinks

We needed to move to Next.js for better performance and a modern CMS, but couldn't afford any ranking drops.

## Step 1: URL Mapping

The first and most critical step is ensuring URL parity:

```ts
// next.config.ts
async redirects() {
  return [
    // Map any changed URLs
    {
      source: '/old-path/:slug',
      destination: '/new-path/:slug',
      permanent: true, // 301 redirect
    },
  ];
}
```

**Golden Rule**: If a URL existed before, it must either:
1. Still exist with the same content
2. 301 redirect to the new location

## Step 2: Metadata Preservation

Every page needs identical metadata:

```tsx
export async function generateMetadata({ params }): Promise<Metadata> {
  const post = await getPost(params.slug);
  
  return {
    title: post.title,
    description: post.excerpt,
    openGraph: {
      title: post.title,
      description: post.excerpt,
      type: 'article',
      publishedTime: post.date,
    },
  };
}
```

## Step 3: Structured Data

Don't forget JSON-LD structured data:

```tsx
<script
  type="application/ld+json"
  dangerouslySetInnerHTML={{
    __html: JSON.stringify({
      '@context': 'https://schema.org',
      '@type': 'Article',
      headline: post.title,
      datePublished: post.date,
      author: {
        '@type': 'Person',
        name: 'Author Name',
      },
    }),
  }}
/>
```

## Step 4: XML Sitemap

Generate a dynamic sitemap:

```ts
// app/sitemap.ts
export default async function sitemap(): Promise<MetadataRoute.Sitemap> {
  const posts = await getAllPosts();
  
  return posts.map((post) => ({
    url: `https://example.com/posts/${post.slug}`,
    lastModified: post.updatedAt,
    changeFrequency: 'monthly',
    priority: 0.8,
  }));
}
```

## The Result

After the migration:
- **0% traffic loss** in the first 30 days
- **15% improvement** in Core Web Vitals
- **Full CMS integration** with TinaCMS for non-technical editors

The key is meticulous planning. Map every URL, preserve every meta tag, and test thoroughly before going live.
